# 利用者アカウント ログインIDルール

## IDルール(既存アカウントからの整理)

既存アカウントの例:

| ログインID | 利用者名 | 構成 |
|---|---|---|
| akusano001 | 草野あかり | a(名の頭文字) + kusano(姓) + 001 |
| atada001 | 多田 文香 | a + tada + 001 |
| ktakemoto1 | 竹本 和将 | k + takemoto + 1 |
| ktsuji001 | 辻 可菜子 | k + tsuji + 001 |

ルール:

1. **名(ファーストネーム)のローマ字頭文字 1 文字 + 姓のローマ字 + 連番** で構成する。
2. 連番は原則 3 桁の `001`(同一IDが既に存在する場合は `002`, `003`… と繰り上げ)。
3. 全体は **10 文字以内** に収める。`頭文字+姓+001` が 10 文字を超える場合は、連番の桁数を削って 10 文字に収める(例: 竹本 和将 → `ktakemoto001` は 12 文字のため `ktakemoto1`)。
4. 使用文字は半角英小文字・数字(システム上の制約はログインID 6〜12 文字の半角英数字記号)。

導出:

- 池嶋真吾 (Shingo Ikeshima) → `s` + `ikeshima` + 連番。`sikeshima001` は 12 文字のため 10 文字に短縮し `sikeshima1`。
- 岡本祥子 (Shoko Okamoto) → `s` + `okamoto` + 連番。`sokamoto001` は 11 文字のため 10 文字に短縮し `sokamoto01`。
- 臼井美紗子 (Misako Usui) → `m` + `usui` + `001` = `musui001`(8 文字、短縮不要)。

既存 4 アカウントおよび新規 3 アカウント間で重複なし。

初期パスワードはこのドキュメントには記載しない。発行時は「ログイン時に強制変更する」を有効にすること。
