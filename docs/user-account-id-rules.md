# 利用者アカウント ログインIDルール

## IDルール(既存アカウントからの整理)

既存アカウントの例:

| ログインID | 利用者名 | 構成 |
|---|---|---|
| akusano001 | 草野あかり | a(名の頭文字) + kusano(姓) + 001 |
| atada001 | 多田 文香 | a + tada + 001 |
| ktakemoto1 | 竹本 和将 | k + takemoto + 1 |
| ktsuji001 | 辻 可菜子 | k + tsuji + 001 |

ルール:

1. **名(ファーストネーム)のローマ字頭文字 1 文字 + 姓のローマ字 + 連番 `001`** で構成する(同一IDが既に存在する場合は `002`, `003`… と繰り上げ)。
2. 全体はシステム制約の **12 文字以内**(半角英数字記号 6〜12 文字)に収める。12 文字を超える場合のみ連番の桁数を削る(既存の `ktakemoto1` は旧運用による例外)。
3. 使用文字は半角英小文字・数字。
