- 採用CAC・媒体選定・追加予算の目処を明確にした上で意思決定する方針のため、本日付議するもの

**コストレンジ: min260万円〜MAX472万円**

- min260万円 = 採用不調で追加施策を打たず、成果報酬も発生しない場合でもかかる下限
- MAX472万円 = 採用不調で追加施策(プランB)まで実施した場合

## 5. 施策内容(プランA: 6媒体)

- **追加スカウト(既存4媒体)**: YourTrust / Wantedly / Herp / 副業クラウド
- **新規開設(2媒体)**: ウルマップ / スタクラ(検討詳細はAppendix)

**コスト構造の特徴**

- 費用は「媒体費用+スカウト追加費用+成果報酬(HERP経由の採用時30万円/件)」のみ
- findyのようなレベシェア・月額手数料型の媒体はなし → **採用後のランニングコストは発生しない**
- ウルマップは契約縛りなし(前月までの連絡で解約可)。月額3万円プランでMIN8〜9月掲載の想定

## 6. リスクと前提

- **離脱を加味し、10月以降も採用継続を想定**
  - 10月採用人数SIM(MAX): オンボーディング離脱4名(ここまでの実績値)+トライアル離脱3名(8〜9月のトライアル対象10名)
  - 11月: トライアル離脱3名(9〜10月のトライアル対象26名)
- 基本線はプランA。採用不調時はさらなる媒体追加(プランB)の可能性があり、その場合を含むコストの着地レンジは**min260万円〜MAX472万円**

### ウルマップ(urumap)

- 母集団: 登録者2万人(営業職のみ)。フリーランス50%・複業30%、20〜30代が6割、女性は約1割(約2,000人)。掲載商材数80、業務委託求人がほとんど
- プラン
  - 成果報酬プラン: 1応募クリック5,000円(初期・月額不要。条件不一致や1週間連絡不通は応募数から除外可)
  - ライトプラン: 月3万円(6応募あれば成果報酬プランと同等。クリック成果報酬なし)
  - スタンダードプラン: 月5万円(ライト+一次対応代行)
- 方針: 月額3万円でMIN8〜9月掲載。単月で1名採用できればCAC3万円
- 成果報酬プランで開始し、6応募到達で月額3万円プランへ移行することも可能 → どれだけ応募・採用が来ても月額3万円以上かからない
- 契約縛りなし(前月までの連絡で解約可)。ヒアリングシート回答から1週間程度で掲載可
- メルマガでの女性セグメント配信ができないか相談中

### スタクラ

- 母集団: 登録者4万人、うち営業経験者1万人。個人営業×業務委託×25〜40歳で絞ると220人
- プラン
  - ①レベシェア型: 採用決定時fee一律20万円+CPに支払う報酬の15%を月額(契約がある限り発生)
  - ②月額利用型: 初期費用15万円+月額15万円(最短6ヶ月〜)
- スカウト送付通数・求人掲載数は上限なし、送付代行あり。申込から利用開始まで最短2営業日

### ハイプロ

- 母集団: 登録者7万人(すべて複業・業務委託人材)。年収600万円〜が60%以上のミドル〜ハイ層、20〜40代がボリュームゾーン。営業周り職種10,500人(15%)、個人営業ソートで2,884名
- プラン
  - ①サブスク型: 月30万円(最短6ヶ月〜。3ヶ月にできないか交渉中)
  - ②成功報酬型: 採用決定1件につき48万円

**SHE求人の勝ち筋(訴求ポイント)**: フルリモート・固定+インセンティブ。他社掲載スクールはシフト制・夜間MTG必須・時給制が多く、自由度や兼業可能性を打ち出せる。
