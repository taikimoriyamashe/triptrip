## 1. サマリー

- **何が起きているか**: パルスの3指標（仕事・対人・健康）が計測開始（2025年11月）以降の最低。特に健康（睡眠）は 3.63 → 3.28、雨以下が 21.3%（約5人に1人）[S1]。悪化は6月に始まり、7月と9月にアラート数が倍増する階段状。
- **どれくらい深刻か**: 全社的で、9月アラート21名のうち16名が新規流入 [S1]。管理職層（U長・サブU長・GM・TM・執行役員）の下落幅がメンバーより大きく [S3]、直近で退職8名・休職1名が報告されている [M]。一時的な波ではなく継続トレンド。
- **構造（仮説）**: グロスタ未達を他部門がカバーする動き（シフトイン・兼務・応援）で負荷が横に広がり、体調不良と離脱が連鎖し、残った人の負荷と喪失感が増す。3月の組織サーベイと7/15の役員HR定例で既に見えていたが、意思決定に至らず夏を越した [S5][N1][N5]。稼働データはなく、棚卸し（A-1）で検証が必要。
- **何をすべきか**: (A) 役員合宿で「負荷の遮断」「人員の意思決定」「産業保健ルートの起動」を先に決める。(B) キックオフ合宿で**会社として現状を認めるメッセージを出す（推奨: 出す）**。ただし(A)の決定と法務確認を伴うことが条件で、「健全な新陳代謝」というフレーミングは使わない。エフィカシー企画は一部調整する。(C) 3〜6ヶ月で有期雇用の包摂、兼務ルール、組織課題のエスカレーション経路を仕組み化する。

### 4-2. 仮説: 負荷が横に広がるループ

以下は上記の事実から森山が組み立てた因果仮説であり、議事録に明示された結論ではない。**証拠の強さについて**: シフトイン・兼務への直接言及は9月自由記述で3件（シフトイン2・兼務1）にとどまり、最大テーマは業務過多/人手不足（3ヶ月18件）[C]。ループの中核は7/15議事録の懸念表明 [N1] と整合させた仮説であり、稼働データはない。A-1の棚卸しは施策であると同時に仮説検証である。

1. **起点**: グロスタ等の目標未達を、LKS等の他事業・他部門がカバーする（7/15定例で懸念として明記）。
2. **負荷の横展開**: カバー手段がシフトイン・兼務・応援・採用偏重となり、事業推進・マーケ・HR・アドミニ・開発の中核正社員と管理職層に「本業＋α」が乗る。稼働実態が打刻に表れず（[C]: 稼働把握の要望）、組織が気づきにくい。
3. **健康の先行悪化**: 頭の切り替え・時間調整のコストが睡眠に出る（Q3急落 [S1]）。育児・家庭との両立に関する言及が多い（3ヶ月14件、感謝を含む [C]）。両立層の悪化が先行するかは属性別データがなく未検証。
4. **離脱と連鎖**: 体調不良 → 休職・退職。残った人は引き継ぎに加え「同僚が倒れるのを見る」負荷と喪失感を抱える（[C]: 周囲の体調不良 15件、退職・喪失 2件）。
5. **不信への転化**: 構造課題が個別フォロー中心で処理され続けると「組織課題がお気持ち課題に変換される」不信が生まれる（[C]: マネジメント不信 7件）。目標未達時の契約見直し示唆のような評価プレッシャーが重なると萎縮が加速する [N3]。
6. **再び起点へ**: 人が減り生産性が落ち、未達がさらにカバーを必要とする。

### 4-4. なぜ夏を越してしまったか（仮説）

- 役員HR定例のパルス関連議題は 3月・4月・6月・7/15 とも「結論：」欄が空欄。個人フォロー（NA）は動くが、**構造的な意思決定（人員配置・止める業務）が議題として閉じない** [N5]。過去にも個別ケースの議題が結論欄空欄のまま閉じた例がある [N5]。
- 3月時点では高ストレス者3名・産業医面談希望0名と個人レベルの信号が弱く、「負荷は高いが持っている」と見えた可能性がある [N1]。
- 「ゾス」「アゲ」であらねばという文化的プレッシャーが個人の負荷になることは2025年7月のケースで既に指摘されている [N3]。前向きなメッセージングが強い組織ほど疲れを言い出しにくい。

### B. 1〜2ヶ月（キックオフ合宿とその後）

#### B-1. 全社メッセージングの是非: **出す（推奨）**。ただし A層の決定と法務確認を伴うことを条件とする

論点「キックオフ合宿のような全社機会で会社としてこの状況をどう捉えているかのメッセージングを出すか」[M] への回答。

**結論**: 出す。CEOがキックオフのオープニング（戦略共有の前）で、5〜10分、会社として現状を認め、打っている手と期限を伝える。

**理由**:

1. **既に知られている**。回答者の24.5%が雨以下を付け、「どの部署もギリギリ耐えていそう」（管理職層）や退職を悼むコメントが出ている [S1][C]。沈黙は「把握していない」か「把握しているが触れない」と読まれ、後者は「お気持ち課題に変換される」不信を強める。
2. **新規流入が主**である以上、今いる人の負荷を減らす決定を伝える場が要る。退職者の話に終始しない。
3. **エフィカシー企画との整合**。「私たちならできる」を3回言うルール [K] は、現状を認めないまま行うと「ゾス・アゲ」のプレッシャーとして働く [N3]。先に現実を認めることで、前向きな宣言が成立する。
4. **条件**: (i) A-1〜A-3 の決定がないままメッセージだけ出すと、次回パルスで悪化した場合に信頼を失う。**9/18で方針決定、9/30でA層の実行確認が得られなければ(b)（ユニット長がユニットキックオフで現状と対応を話す形）に切り替える**（温度差は出るが、決められないうちはその方が誠実）。(ii) **メッセージ文言は法務または社労士の確認を経る**（全社の場での発言は記録に残るため）。

**検討したが採らなかった反対論**:

1. 労務紛争時に発言が記録として残るリスク → 法務・社労士確認を条件化し、個別退職との因果を語らない（B-2）。
2. 退職の理由内訳が未確認のまま原因を語るリスク → Q-0で9/18までに先に確認する。
3. 候補者・取引先への流出リスク → 数値は言わず「厳しい状況」と定性表現に留める選択肢（Q-1 (a')）を併記。
4. 知らなかった層に不安を配るリスク → 打ち手と期限をセットで語ることで対処。不安を配らないために沈黙する方が、後で知ったときの不信が大きい。

| **法的義務の履行状況が方針に載っていない** | 安全配慮義務、ストレスチェック後の集団分析に基づく措置、長時間労働者・高ストレス者への医師面接指導の履行状況が、これまでの役員HR定例の議題に整理されていない。方針が「メッセージと負荷調整」に寄ると、義務の履行が抜ける | A-7で産業医ルートを起動し、履行状況を役員HR定例で確認。C-8で外部窓口を補完。A-5の上限設定に産業医意見を入れる |

| **仮説の誤り** | 4-2のループは稼働データのない仮説。応援業務を止めても改善しない場合、原因は組閣・事業不安・母集団変化（4-3）にある可能性 | A-1の棚卸しを仮説検証として扱い、9/30と10月パルスで見直す |
| **数値の読み違い** | シートのダッシュボードは旧定義混在。速報値（9/2時点20名）と人単位再計算値（21名）は概ね一致するが、行単位で集計すると重複送信で過大になる | 本文書は人単位の再計算値を使用。次回以降の定例で定義と集計方法（人単位・現行アラート定義）を固定する |
| **9月組織サーベイとの二重負荷** | パルスと組織サーベイが同時期に走ると回答負担・「聞かれるだけ」感が増す | B-4aで実施時期を調整し、結果開示の約束（B-2）をセットで案内する |
