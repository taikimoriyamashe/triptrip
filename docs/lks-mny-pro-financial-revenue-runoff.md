## 検証（独立レビュー済み）

- 「FY26_経営モニタリング」スプレッドシートの「実績」ブロック（_LKS/_MNY/_プロデ 行）と、2026-08以降の全月が1円単位で一致することを確認。
- LKS = likesオンライン + likesオフライン（拠点: 福岡・名古屋・梅田・横浜等）。例: 2026-09 は 211,936,299 + 15,259,022 = 227,195,321。
- プロ = `likespro財務会計`（シート上の「_プロデ」、Lightdash `view_sales_accounting` では multicreator に対応）。
- MNY の2026-12以降のマイナスは全額 `money月額費財務会計` 由来（解約返金・按分戻し等が新規計上を上回るため）。`money入会金財務会計` は2026-09以降ゼロ。
- 独立レビュアーがBigQueryを再クエリし、13ヶ月×3サービスの全数値・期間集計・定義・データ終端（2027-08）・鮮度を照合済み（全一致）。

## 注意事項

- 2026-08 は月中時点の成約済み分。8月中の新規成約で着地はここから増加する（着地見通しのヨミは `likes_monthly_online_revenue_forecast` 系の別モデル）。
- スプレッドシートの過去月（2026-04〜07）にはBQ値に手入力調整が加算されている（例: 2026-07 MNY +2,000,000）。将来月には手入力調整なし。
- Lightdash の `view_sales_accounting`（sheincデータセット）の likes は月額費が本マートより毎月約1,500万円大きい（定義差）。経営モニタリングと突合する場合は本マート（official_monitoring）を使用すること。
- 法人・グロスタは依頼対象外のため含まない。
