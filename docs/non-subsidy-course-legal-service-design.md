## 1. サマリー

- **前提となる事実**: 厚生労働大臣指定講座「SHElikes Webデザイン トレーニングプログラム」（教育訓練給付金対象）とは別に、給付対象外の自習形式講座（非指定講座）を新規販売する。2026-08-26に厚労省へ事前共有メールを送付し、2026-09-04に回答を受領した。
- **厚労省回答の意味**: 回答の趣旨は「指定を希望しない講座について、厚労省が内容等を確認し、意見を申し上げることはない」というもの。すなわち、
  - 国は非指定講座の内容・広告・価格設計を**確認しない**。事前承認やお墨付きを与える制度は存在しない。
  - **「懸念なし」という回答は得られていない**。本回答を「厚労省が問題ないと言った」と解釈・説明することは、社内外を問わず厳禁。
  - 誤認防止と指定基準の遵守は、**全面的にSHEの自己責任**で担保する。
- **本文書で確定させること**: 上記を前提に、(1) 遵守すべき法令・基準の棚卸し、(2) 商品設計・Web表記・申込フロー・社内運用の4領域にわたるサービス設計要件、(3) 実行タスクと残論点を整理する。特に、SHEが厚労省へのメールで**対外的に表明済みの2つのコミットメント**（①表形式による明確な識別表記 ②利用規約・明示書への給付対象外の明記）は、任意の施策ではなく**遵守義務のある約束事項**として設計に組み込む。
- **最大のリスク**: 非指定講座の設計・広告が指定講座の指定基準（特に二重価格の禁止、広告・募集時の留意点）に抵触すると評価された場合、**指定講座側の指定に影響が及びうる**（更新不可・指定取消等の可能性を含む。具体的な法的効果の整理は弁護士確認要）。非指定講座は「別商品だから自由」ではなく、指定講座を守る観点から設計する。

## 3. 遵守すべき法令・基準の棚卸し

各項目を「基準・条文の趣旨 → 本件でのリスクシナリオ → 設計上の対応」の形で整理する。設計上の対応の詳細は4章に展開する。なお、本章の「趣旨」は基準・条文の原文引用ではなく一般的理解に基づく整理である。指定基準原文との突合はT-4/T-17で実施する。

### 3-1. 教育訓練給付制度の指定基準

#### (a) 二重価格の禁止

- **趣旨**: 指定講座の受講費用を、給付金の受給有無によって区別してはならない。給付対象者だけ実質高く（または安く）なる価格設計は、給付制度の適正性を損なう。
- **リスクシナリオ**: 非指定講座を指定講座の「廉価版」として設計し、内容の実質が指定講座と同等なのに価格だけ大幅に低い場合、「給付を使わない人向けの実質値引き＝指定講座の二重価格」と評価されるおそれ。また、非指定講座受講者が後から指定講座に乗り換える際の差額運用（受講料充当・割引）が、結果として給付受給有無による価格差を生む形になるおそれ（→ Q-3）。
- **設計上の対応**: 非指定講座を講義数・訓練時間・課題数・添削/フィードバックの有無・修了認定の有無すべてで指定講座と明確に異なる**独立商品**として設計し、価格算定根拠を文書化・保存する（→ 4-1）。指定講座側は届出内容どおり、一律同一価格・同一サービスを維持する（メール1通目で表明済みの前提）。

#### (b) 広告・募集時の留意点

- **趣旨**: 給付対象でない講座を給付対象と誤認させる表示をしてはならない。「厚生労働大臣指定」「教育訓練給付金対象」等の表記は、指定講座にのみ使用できる。
- **リスクシナリオ**: 非指定講座のLP・広告に「教育訓練給付金」の語が並存し、対象外であることが読み取りにくい／指定講座の実績・指定表記が非指定講座の訴求に流用される／同一ブランド（SHElikes）配下の販売のため、受講希望者が「SHEの講座＝給付対象」と包括的に誤認する。
- **設計上の対応**: 表形式の識別表記（表明済みコミットメント①）、給付対象外である旨の表示位置・文言の標準化、禁止表現リストの整備、媒体別（アフィリエイト・SNS広告等）の統制（→ 4-2）。

### 3-2. 景品表示法（優良誤認・有利誤認の防止）

- **趣旨**: 商品・役務の内容や取引条件について、実際よりも著しく優良・有利と誤認させる表示は禁止される（景品表示法5条）。給付金の適用有無は取引条件の中核であり、対象外の講座を対象と誤認させる表示は有利誤認に該当しうる。
- **リスクシナリオ**: 非指定講座の広告が給付適用を示唆する／指定講座との比較表で非指定講座に不利な条件（添削なし・修了認定なし等）を殊更小さく表示する／「最大◯%お得」等の表現が給付適用を前提とした比較として読まれる。アフィリエイター等の第三者媒体が誤認表示を行った場合も、SHEの表示として責任を問われうる。
- **設計上の対応**: 比較表の必須掲載項目の固定（不利な差異も同格で表示）、給付関連の語を非指定講座の訴求に用いない禁止事項、媒体審査・アフィリエイト規約への反映、公開前法務レビュー（→ 4-2 / 4-4）。

### 3-3. 特定商取引法

- **趣旨**: 通信販売に該当する場合、広告への法定表示事項（販売価格、支払時期・方法、役務提供時期、事業者情報等）の記載義務と誇大広告の禁止が課される。
- **リスクシナリオ**: 非指定講座のLPで法定表示事項が不足する／「誰でも簡単に」型の誇大広告と評価される表現を使う。また、**SHElikesの契約形態が特定継続的役務提供に該当する場合**、概要書面・契約書面の交付義務やクーリングオフ等、より重い規律が適用される。非指定講座（自習形式）の該当性は契約期間・金額・役務の性質によるため、現時点で断定しない。
- **設計上の対応**: LP・申込画面の法定表示事項チェックリスト化（→ 4-2 / 4-3）。**特定継続的役務提供該当性は要確認事項として先行整理し、弁護士確認要**（→ Q-1）。該当する場合、明示書は法定書面（概要書面等）と統合または整合させて設計する。

### 3-4. 消費者契約法（不利益事実の不告知の回避）

- **趣旨**: 重要事項について消費者の利益になる旨を告げつつ、不利益となる事実を故意・重過失で告げなかった場合、消費者は契約を取り消しうる。
- **リスクシナリオ**: 「給付対象外であること」は受講費用の実質負担に直結する重要事項であり、申込判断に影響する。低価格・手軽さを訴求しながら給付対象外である事実の表示が不十分な場合、不告知と評価され、契約取消・返金対応・行政（消費生活センター経由）対応に発展しうる。
- **設計上の対応**: 給付対象外である旨を申込前の複数接点（LP比較表・申込画面・利用規約・明示書）で明示し、申込前の同意チェック等で認識を確認・記録する（→ 4-3）。表明済みコミットメント②はこの規律への対応そのものとして位置づける。

### 4-1. 商品設計の独立性担保（二重価格禁止への反証可能性）

非指定講座が指定講座の「実質値引き版」ではなく独立した別商品であることを、後から第三者（厚労省・弁護士・消費者）に説明できる状態を作る。

| 要件 | 内容 |
| --- | --- |
| 商品差異の確定と文書化 | メールで表明した差異（動画講義数・総授業時間は大幅に少ない／演習課題提出数は少ない／講師指導・個別質問対応・添削・フィードバックは一切なしの自習・独学形式／合否判定・修了認定・修了証なし）を、仕様書として数値レベルで確定し文書化する |
| 価格算定根拠の文書化・保存 | カリキュラム時間・サポート体制の違いに基づく料金算定の根拠（原価・工数・市場比較等）を文書化し、保存期間を定めて保管する。「なぜこの価格か」を指定講座の価格から逆算した値引きとしてではなく、非指定講座単体のコスト・価値から説明できる形にする |
| 指定講座側の不変性維持 | 指定講座は届出内容（講義内容・訓練時間数・受講費用・修了認定基準）どおりの運営を継続し、給付受給希望の有無による価格・取扱いの区別を一切行わない。非指定講座の展開を理由に指定講座側の仕様・価格を変更する場合は、随時届出フローを先に確認する |
| 乗り換え・併売時の価格運用 | 非指定講座→指定講座の乗り換え時に差額充当・割引等を行う場合、それが指定講座の実質的な価格差（二重価格）と評価されないかを事前に整理する。**整理が済むまで乗り換え割引は実施しない**（→ Q-3、弁護士確認要） |

## 8. 体制と進め方

### 8-1. 体制

- **ボール持ち**: 森山（Taiki Moriyama）
- **主管**: 中野（CFO室）※要確認（→ Q-4）。厚労省窓口・価格算定・更新申請準備の一次担当を想定
- **意思決定**: 取締役（設計方針の承認、販売開始日、社外弁護士レビュー範囲の裁定）
- **主な実務担当**: 法務/アドミニ（規約・明示書・レビューフロー・弁護士連携）、マーケ（比較表・LP・広告・媒体統制）、CS（応対スクリプト・誤認事案記録）、プロダクト（申込フロー・同意チェック実装）

### 8-2. 進め方（順序）

1. **本文書を取締役に持ち込み**、設計方針の承認と、社外弁護士レビューの要否・範囲（Q-8）、販売開始日との依存関係（Q-9）の裁定を得る。
2. **法令上の前提確認を先行**: 特定継続的役務提供該当性（T-9/Q-1）と随時届出整理の妥当性（Q-5）。明示書・規約の設計（T-6/T-7）はこの結論に依存するため最優先。
3. **商品・価格の独立性を固める**: 商品仕様書（T-1）と価格算定根拠の文書化（T-2）。乗り換え運用（T-15/Q-3）の整理が済むまで乗り換え割引は実施しない。
4. **表示・フローの実装**: 比較表・表示ガイドライン・禁止表現リスト（T-3/T-4）、規約・明示書・同意チェック（T-6/T-7/T-8）を並行で実装し、公開前法務レビュー（T-10）を通す。
5. **運用の立ち上げ**: CSスクリプト（T-11）、誤認事案の記録・エスカレーション（T-12）、誤認申込時の対応基準（T-13）、記録保存体制（T-14）を販売開始前に整える。
6. **関係者周知（T-18）**を販売開始前に完了し、「厚労省回答はお墨付きではない」認識を統一する。
7. **販売開始後**: 誤認事案のモニタリング（T-12）を継続し、媒体監査（T-5）と更新申請準備（T-16）を運用に乗せる。

> 各ステップの期日は未設定。販売開始のブロッカーとするタスクの確定（Q-9）とあわせて、取締役持ち込み時に決める。
