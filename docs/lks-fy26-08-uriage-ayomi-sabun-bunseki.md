## 1. サマリー

LKSの8月売上は、**管理会計で実績がAヨミを+1,346万円上回り(ほぼBヨミに一致)、財務会計では逆に▲669万円下回った**。両会計で乖離の方向が逆という特徴的なパターンであり、要因は次の3層に分解・特定できた。

| | 管理会計 | 財務会計 |
| --- | ---: | ---: |
| 期初計画 | ¥390,936,684 | ¥355,646,518 |
| Aヨミ | ¥390,496,916 | ¥361,696,128 |
| **実績** | **¥403,960,742** | **¥355,002,075** |
| **実績 − Aヨミ** | **+¥13,463,826 (+3.4%)** | **▲¥6,694,053 (▲1.9%)** |
| (参考) Bヨミ | ¥404,889,150(実績と▲93万差) | ¥362,147,895 |

※Aヨミ・実績は経モニ「通期着地見通し」2026-08列(9/1時点)。実績はDWH(BigQuery)と突合済み — 管理会計は**円単位で完全一致**、財務会計は差13,636円(キャンセル手数料の扱い差)のみ。

**要因の結論(3層):**

1. **【直接要因・管理会計 +1,346万】成約数ヨミのずれ(逆方向の2つが相殺)**
   - レギュラー成約: ヨミ645〜662件 → 実績 759件(**約100件の過少ヨミ**)→ 入会金 **+1,490万**
   - スタライ成約: ヨミ208〜209件 → 実績 164件(**約44件の過大ヨミ**)→ 入会金 **▲580万**
   - ※実績件数はDWH直接値(759/164)。売上からの単価逆算(±2件精度)でも同水準で裏取り済み
2. **【直接要因・財務会計 ▲669万】ストック(会員数)と単価前提のずれ**
   - レギュラー入会金按分 **▲636万**(うち68%=入会金単価前提の過大 [ヨミ153,500円 vs 実勢推計146,127円]、32%=会員数下振れ)
   - レギュラー月額 **▲399万**(レギュラー会員数がヨミ比 **▲約166人**。この会員数下振れは2つの独立な計算系統で一致するロバストな推計)
3. **【構造要因】"Aヨミ"が組織内で単一の数字になっていない**
   - 同一の「LKS 8月Aヨミ」に対し、**経モニ内エンジン・BQ(DWH)モデル・SSK着予の3系統**が併存し、会員数・単価・成約数・クーオフ控除の前提がすべて異なる(§4)。8/25取締役会での「経モニ944件 vs SSK911件」の混乱はこの構造の必然的な帰結。
   - BQモデルは**「確定待ち月は least(提出値, 実績)」ルール+毎月15日の境界自動昇格**により、直前月・当月が好調なほど構造的に保守化する仕様(実績759件 > 提出661件でも661件を採用し続けた)。**証跡が最も強い構造要因はこれ**。
   - 加えて8/25時点のAヨミ911件は、SSK資料自体に**「月末3日間(8/29-31)の成約増が件数ベースで未確定」と明記されたまま**算出されていた。月末施策の未反映は件数上振れの有力な説明の一つである(ただし8/29-31の日次実績・施策成果の一次証跡は未取得。§7参照)。
   - 経モニのAヨミは日次で再計算され**スナップショットが残らない**ため、報告時点の数字を事後検証できない(BQ側には日次履歴が実在するが、報告に使われていない)。
   - 経モニの一次シート(FY26_単月確認用)のAヨミ列に**#N/A・破損セルが多発**し、壊れた値がKPI行(売上着地見込み35.45%)まで伝播。さらに**通期着地見通しの実績系列に拠点月額費の二重計上(8月+1,304万円)**を検出(§5)。

再発防止策は§6に短期(9月サイクルから)/中期/恒久の3段で提示する。

## 2. 差分の定量分解(円単位で完全整合)

経モニ全シートのダンプとDWHを突合し、差分を構成要素に分解した。**管理・財務とも、構成要素の和が差分合計に仮定なしで一致**する(検算23件PASS)。

### 2-1. 管理会計 +¥13,463,826 の内訳

| 構成要素(オンライン) | Aヨミ | 実績 | 実績−ヨミ | 寄与率 |
| --- | ---: | ---: | ---: | ---: |
| レギュラー入会金 | 99,012,512 | 113,915,600 | **+14,903,088** | 110.7% |
| スタライ入会金 | 28,242,656 | 22,447,460 | **▲5,795,196** | ▲43.0% |
| 残差(月額オンライン+拠点) | 263,241,748 | 267,597,682 | +4,355,934 | 32.4% |
| **合計** | **390,496,916** | **403,960,742** | **+13,463,826** | 100% |

- レギュラー入会金の+1,490万は**成約件数ずれ**そのもの: ヨミ645〜662件相当に対し実績は759件(DWH直接値。単価逆算・昨対比シート923件でも裏取り)。
- スタライ入会金の▲580万も**成約件数ずれ**: 経モニのヨミは提出値208〜209件相当のままだったが、実績は164件(DWH直接値)。なお**BQモデル側は「実績を採用(確定待ち)」で164件に補正済み**であり、経モニ側だけが過大のまま残った(=エンジン間の成約数前提の乖離、§4)。
- 拠点はほぼ着地(残差から+17万〜+160万の小幅超過と推計。拠点Aヨミの直接値はブック内に存在せず残差推計、前提依存の暫定判断)。

### 2-2. 財務会計 ▲¥6,694,053 の内訳

| 構成要素(オンライン) | Aヨミ | 実績 | 実績−ヨミ | 寄与率 |
| --- | ---: | ---: | ---: | ---: |
| レギュラー入会金(12ヶ月按分) | 90,260,303 | 83,898,641 | **▲6,361,662** | 95.0% |
| 月額費用計(レギュラー月額▲399万が主) | 235,311,349 | 231,566,017 | **▲3,745,332** | 56.0% |
| 残差(スタライ入会金+拠点等) | 36,124,476 | 39,537,417 | +3,412,941 | ▲51.0% |
| **合計** | **361,696,128** | **355,002,075** | **▲6,694,053** | 100% |

- レギュラー入会金按分▲636万の単価×数量分解: **単価前提の過大が68%**(ヨミ153,500円/人 vs 実勢推計146,127円/人 = +5.0%過大)、**会員数下振れが32%**。
- レギュラー月額▲399万は**会員数ずれ**: ヨミ7,056.18人に対し実績逆算6,889.8人(**▲166.4人、▲2.4%**)。BQ系統の前提(6,786.28人、単価24,500円)で逆算しても▲164.1人となり、**「レギュラー会員数が約165人下振れ」は前提によらず成立**。
- スタライ系はほぼ的中(月額+0.4%)。会員数モデルの精度問題はレギュラーに集中している。

### 2-3. なぜ管理と財務で符号が逆になったか(本質)

8月は **「フロー(当月成約)は上振れ、ストック(既存会員数)と単価前提は下振れ」** が同時に発生した。

- 管理会計は入会金を**成約時に全額計上**するため、レギュラー成約+約100件が即座に+1,490万円として効いた。
- 財務会計は入会金を**12ヶ月按分**するため、8月成約の上振れは8月財務にはほぼ効かず(効くのは9月以降)、代わりに**既存会員数の下振れ(▲166人)と単価前提の過大**がそのまま▲669万円として現れた。

つまり両者は矛盾しておらず、**同じ「ヨミモデルの前提ずれ」が会計基準の違いで逆符号に見えている**。

## 3. 件数の整合 — 944 / 911 / 923 / 1,035 の正体

8月に飛び交った成約数の数字は、集計範囲とクーオフ控除の定義が異なる別物である。

| 数字 | 出所 | 定義 |
| --- | --- | --- |
| **944件** | 経モニ(8/25時点、取締役会報告) | 経モニのAヨミ(オンライン+拠点、クーオフ控除前とみられる)。9/1時点の経モニヘルパーでは945 |
| **911件** | SSK週次(8/25) | **クーオフ率15%を控除した着地予測**: OTL794件+拠点117件。取締役会で「Aヨミ=911件」と合意 |
| **923件** | 実績(オンライン) | レギュラー759+スタライ164(DWHで確認、クーオフ確定前のグロス) |
| **1,035件** | 実績(LKS全体) | オンライン923+拠点112 |

- 経モニ944(クーオフ控除前とみられる) vs SSK911(クーオフ15%控除後)は**そもそも定義が異なる数字の比較**であり、「33件の乖離」の相当部分は定義差で説明されうる(仮に944がグロスなら15%控除で約802件となりOTL794と近い水準。ただし944の内訳定義は未確認、§7)。この確認が取締役会の場で必要になったこと自体が、定義不統一のコスト。
- 実績はグロス1,035件で、経モニのグロス系Aヨミ944件を+91件上回った(なおSSK側の8/25時点グロス着予はオンライン934件で、オンライン実績923件はこれを11件下回っており、上振れの度合いは系統によって見え方が異なる)。SSK資料自体に「月末3日間(8/29-31)でどう山を作るかが最大論点。**得られる成約増の見積もりとシフト・枠数が紐づいていない**」と明記されており、**月末施策の効果が数値化されないままAヨミが報告された**ことは件数ずれの有力な説明の一つである(8/29-31の日次実績の一次証跡は未取得、§7)。
- なお、8/25時点の944/911件をデータ基盤側で正確に再現することは、ヨミ入力履歴テーブルの成約数列が非公開のため現状不可能(§7)。

## 4. 構造要因: 「Aヨミ」が単一の数字になっていない

### 4-1. 3系統のAヨミが併存している

| 系統 | レギュラー会員数 | 入会金単価/月額単価 | スタライ成約前提 | クーオフ | 日割補正 |
| --- | ---: | ---: | ---: | --- | --- |
| **経モニ内エンジン**(単月確認用+会員数ヨミシート) | 7,056.18人 | 153,500 / 24,000 | 208〜209件(提出値のまま) | 控除前(推定) | なし |
| **BQ(DWH)モデル**(likes_monthly_online_revenue_forecast) | 6,786.28人 | 149,627 / 24,500 | 164件(実績でキャップ) | — | あり(×372/365) |
| **SSK着予**(事業側週次) | — | — | — | **15%控除後** | — |

- 同一ブック(経モニ)の中でも、「通期着地見通し・今月ブロック」のAヨミ(財務361,696,128/管理390,496,916)と「売上サマリ/Aヨミ月次系列」のAヨミ(362,046,128/388,379,169)が**8月だけ35万円/212万円ずれており**、Aヨミは実質4つ存在した。
- 経モニの財務Aヨミ361.7Mは、BQのオンライン限定モデル(約342M)+拠点分(約20M、別シート手当て)という**2段構えである可能性が高い**。根拠は、BQモデル単体の値(339〜343.1Mのレンジ)が経モニのAヨミと一致する日が7/17〜9/1の**全期間で1日も存在しない**こと、および差額約20Mが拠点財務実績18.2Mと近似することによる推定であり、最終確定にはAヨミセルの数式現物の確認が必要(§7)。

### 4-2. Aヨミが構造的に保守化する仕組み(BQモデル仕様)

DWHのヨミモデルは成約数を次のルールで採用する(Devinによるモデル解説スレッドで確認、BQ実データで裏取り済み):

| 対象月 | 採用する値 |
| --- | --- |
| 当月以降 | 事業部の提出ヨミ値 |
| 確定待ち月(直前終了月) | **least(提出値, 実績)** — 実績が上回っても低い方の提出値を維持 |
| 確定月 | 実績 |

さらに境界月は**毎月15日に自動昇格**する(8/15に7月が実績コホートへ切替わり、8月ヨミが+130万〜240万円ジャンプしたことをBQ日次履歴で確認)。

この仕様の帰結として、**直前月・当月の成約が好調な月ほどAヨミは実態より保守的に出る**。8月はまさにこのケースで、レギュラー提出値661件 < 実績759件だったにもかかわらず、モデルは661件を採用し続けた(capped_flg=false、8月は確定待ち扱い)。**「Aヨミ=固いヨミ」という意図の仕様が、上振れ局面では系統誤差になる**。

### 4-3. 報告プロセス上の問題(Slack/SSK証跡より)

- **月末施策の未反映**: 8/25のSSKで「着予3系統(7日平均819/Aヨミ1,021/Bヨミ1,167)の一本化」がようやく前週の論点として収束した直後であり、月末3日間の押上げは「件数ベースで未確定」のまま。7月にも「月末大感謝祭」を7/30当日に急遽決定・実施した前例があり、**月末即興施策がヨミサイクルに構造的に載らない**。
- **ヨミの手動運用**: ヨミ更新は担当者ごとの共有シート手入力(月次で「事推の皆さんヨミ更新よろしく」依頼→各自が決められた列を編集)。過去に二重計上、ヨミと実績の計上場所違い、「ヨミが消えた」騒動(シート保護列の見間違い)などの事故実例がある(いずれもコストヨミでの実例)。6月にはLKS成約Aヨミが約20分間(22:00〜22:19)に770→815→907→901→907と何度も書き換え・確認され、7月には過去月のAヨミ自体が878→935件へ事後改定され将来のコストSIMが連動して作り直された。
- **スナップショット不在**: 経モニのAヨミはXLOOKUPによる日次再計算で上書きされ、「8/25に取締役会へ報告した944件」を後から正確に再現できない。一方、**BQ側には財務ヨミの日次as-of履歴が7/17から完備されている**のに、報告・検証に使われていない。

## 6. 再発防止策

### 短期(9月の報告サイクルから)

1. **「Aヨミ」の定義を1枚で固定する** — 集計範囲(オンライン+拠点)、クーオフ控除の有無(グロス/ネット)、会計基準(管理/財務)、参照元(どのシート・どのモデル)を明文化し、SSK・経モニ・取締役会報告で**同一の値**を使う。8/25の「944 vs 911」の照合作業を二度と取締役会の場でやらない。
2. **報告時点のAヨミをスナップショットとして固定する** — 取締役会・SSKに出した数字は、経モニに「YYYY/MM/DD時点Aヨミ」として値貼り付けで保存(またはBQのas-of履歴テーブルを正式台帳に指定)。事後の予実検証を可能にする。
3. **月末施策の効果を件数でヨミに載せる期日をルール化** — 月末最終週のSSK(今回は8/25)までに、月末施策の期待成約数を幅(min/max)でも良いので数値化してAヨミ/Bヨミへ反映。「未確定」のまま報告する場合は、Aヨミに『月末施策未反映』の注記を必須とする。
4. **§5のシート修正**: 二重計上系列の修正、#N/A/破損セルの修理、当月列の「見込み」ラベル明記、LKS全体_月別比較の8月列補完。修正後、「オンライン+拠点=全体」「構成要素の和=合計」の**検算行を常設**する。

### 中期(FY26下期中)

5. **least(提出値, 実績)ルールの見直し** — 確定待ち月・当月について、実績が提出値を上回った場合は「実績×(1−想定クーオフ率)」を下限として採用する等、**上振れ方向にも追従する**ロジックへ変更(現行は下振れにしか追従しない片側キャップ)。あわせて境界月昇格(毎月15日)前後でヨミが跳ねることを関係者に周知し、月次報告の基準日を15日以降に統一するか、報告時に境界月を併記する。
6. **ヨミエンジンの一本化** — 経モニ内エンジン(会員数7,056人×単価153,500/24,000)とBQモデル(6,786人×149,627/24,500×日割)の**どちらを正とするかを決め、片方に寄せる**。特に単価パラメータ(153,500 vs 149,627 vs 実勢146,127、24,000 vs 24,500)は経理の実勢値で毎月更新される単一のパラメータテーブルに集約する。スタライ成約数がBQ側164件/経モニ側208件と27%ずれたまま並走した状態を解消する。
7. **レギュラー会員数モデルの補正** — 今回▲166人の過大は、退会・休会・クーオフの想定超過が主因とみられる(9/1 SSKでは拠点セグメントで「当月クーオフ16.07% vs 目標14.2%」の記載)。12ヶ月フラット在籍→13ヶ月目消滅という現行コホート仕様(満了後継続の実会員約100人を落とす一方、途中離脱を過小評価)を、実績残存カーブベースに更新する。

### 恒久

8. **予実差の構成要素分解を月次で自動化** — 本分析のフォーマット(管理/財務 × 構成要素 × 単価/数量/件数分解)をBQ上のジョブまたはLightdashダッシュボードとして定常化し、乖離が¥Xを超えた要素だけをSSK/経営会議でレビューする運用にする。手動シートの突合作業を人からシステムへ移す。
9. **手動ヨミ入力の統制** — 提出ヨミの入力をフォーム化(誰が・いつ・どの値を提出したかのログを残す)し、過去月ヨミの事後改定は変更履歴+理由必須とする。
10. **クーオフ確定前の実績の扱いを標準化** — 8月の管理会計実績+1,490万(レギュラー成約上振れ分)は、お試し期間満了(9月中〜下旬)後のクーオフ確定で目減りしうる。月初報告では「クーオフ確定前」を明記し、確定後に差替える二段階報告をルール化する。
