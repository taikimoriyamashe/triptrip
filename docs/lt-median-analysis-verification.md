## 問題点

### ① 予約退会（未来日の退会日）を「退会済み」として集計している ★影響大

`likes_withdrawal_date > 本日` のレコードが item 10/7 で146件。まだ起きていない退会をイベントとして扱い、
かつ観測可能期間より先の LT を与えている。**本日時点で打ち切り（censored）に直すのが正しい。**

FY2025 スタンダード1ヶ月では872件中54件（6.2%）が該当し、補正すると:

- LT中央値: 11ヶ月 → **12ヶ月**
- 12ヶ月継続率: 44.7% → **47.5%**
- 退会率: 48.0% → **44.9%**

FY2022〜2024 はほぼ影響なし（中央値・12ヶ月継続率とも変化なし）。
つまり報告の「13→11ヶ月と短縮」のうち1ヶ月分はこの不具合由来。

### ② FY2025 を年度コホートとして横並び比較しているが、12ヶ月時点に到達しているのは4〜8月入会分のみ ★影響大

FY2025（2025/4〜2026/3入会）1,687件のうち、12ヶ月の観測が可能なのは725件、12ヶ月時点の at_risk は389件。
一方 FY2022〜2024 は通年12ヶ月分が揃っている。KM法は打ち切りを扱えるが、**比較対象の入会月構成が違う**問題は解けない。

全年度を **4〜8月入会に統一**して比較すると（スタンダード1ヶ月）:

| 入会年度（4〜8月） | n | KM中央値 | 6ヶ月継続 | 12ヶ月継続 | 12ヶ月時点 at_risk |
|---|---|---|---|---|---|
| FY2022 | 2,245 | 13ヶ月 | 78.2% | 51.3% | 1,263 |
| FY2023 | 2,458 | 12ヶ月 | 77.1% | 49.5% | 1,359 |
| FY2024 | 2,533 | 13ヶ月 | 77.1% | 50.9% | 1,400 |
| FY2025 | 725 | 12ヶ月 | 76.7% | 48.3% | 383 |

- 12ヶ月継続率のレンジは **3.0pt・非単調**。Devin の「7.5pt低下」は年度コホートの非対称性で約2.5倍に膨らんでいる
- KM中央値は **13/12/13/12ヶ月** で横ばい。「13→11ヶ月と短縮傾向」は支持されない
- 6→12ヶ月の条件付き継続率は 65.6 / 64.2 / 66.0 / 62.9% でほぼ横ばい
  → 「悪化しているのは入会7〜12ヶ月目の中期継続」という結論も過大

### ③ レギュラープラン導入による母集団の質的変化に触れていない ★最も本質的

2024-08にレギュラープラン（12ヶ月契約）が登場し、新規入会の主力が入れ替わっている:

| 入会月 | スタンダード1ヶ月 | レギュラー |
|---|---|---|
| 2024-07 | 554 | 0 |
| 2024-08 | 315 | 321 |
| 2024-09 | 172 | 642 |
| 2025-04 | 149 | 602 |
| 2026-08 | 149 | 747 |

- FY2022/FY2023 のスタンダード1ヶ月は「主力プラン」＝入会者の大半
- FY2025 のスタンダード1ヶ月は「レギュラー（12ヶ月契約）を選ばなかった残余層」＝新規の約2割
- 同じ「スタンダード1ヶ月」という名前でも母集団の性質が違うため、年度推移を継続率の良し悪しとして読むのは危険
- LT/継続率の年度推移を語るなら、この構成変化の明記が必須

### ④ 共有SQLに再実行時の不具合

`min(if(lt_month <= 18, round(s*100,1), null))` は観測が18ヶ月に届いていないコホートでも値を返す。
FY2025 スタンダードでは **0.0%** を返す（最終観測月で at_risk が全て退会し KM曲線が0に落ちるため）。
Devin は Slack の表では手で「－」に置き換えたので報告値自体は無事だが、
このSQLをそのまま再実行した人は誤った値を掴む。`max(lt_month) >= 18` のガードが必要。

### ⑤ 事実の誤り（軽微）

reply 8 の「レギュラー除外による減少は数件」→ **実際は0件**。
レギュラー契約歴を持つ1ヶ月プランのterm自体は26件（FY2024:23, FY2025:3）存在するが、
すべて「スタンダード → レギュラー」の順（アップグレード）で、
Devin のフィルタ条件（レギュラーが先）には1件も該当しない。結論に影響はない。

### ⑥ reply 4 と reply 8 で見出しの結論が反転している

- reply 4（全期間プラン込み）: 「LT中央値は年度を通じてほぼ12〜14ヶ月で**安定**しており」
- reply 8（1ヶ月プランのみ）: 「LT中央値は 2022年度13ヶ月 → 2025年度11ヶ月 と**ゆるやかに短縮傾向**」

同じデータの部分集合なのに逆の見出しになっている。検証結果は reply 4 の「安定」側が正しい。
また reply 8 は「2025年度は参考値扱いで」と注記しながら、その参考値を見出しのトレンド根拠に使っている点も整合していない。

## 推奨する出し直し方

1. 予約退会を本日時点の打ち切りに変更（`likes_withdrawal_date <= current_date` を退会イベントの条件に追加）
2. 年度コホートではなく**入会月を揃えた比較**、または「観測12ヶ月以上のコホートのみ」で比較
3. 18/24ヶ月継続率に観測到達ガードを追加
4. レギュラープラン導入による母集団構成の変化を注記。
   スタンダード/ライト1ヶ月だけでなく**レギュラー含む全体のLT**、
   および**レギュラー→1ヶ月プラン移行組（10,335件）の移行後継続**も併せて見ないと事業実態を見誤る
